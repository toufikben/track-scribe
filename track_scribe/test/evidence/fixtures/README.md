# Evidence fixtures

Ground truth policy: **nothing here claims a field distance it did not
measure.** A fixture is either `synthetic` (generated locally, ground truth
exact by construction) or `real` (recorded on the Realme with the truth
measured from a mapped course — OpenStreetMap routing or a measured loop).

- `synthetic/` — generated by `dart run tool/replay.dart --gen <path>`.
  Deterministic (fixed seed). Used to calibrate the harness and to prove the
  replay tool works; NEVER cited as device evidence. The golden replay test
  ignores this directory. The `.gpx` files are git-ignored (rebuild them with
  `--gen`; the seed makes the output byte-identical).
- `real/` — one entry per device-recorded course, as soon as an installable
  APK exists (CI is the only builder). Naming: `<sport>-<truth-metres>.gpx`
  plus a sidecar `<sport>-<truth-metres>.gpx.truth` holding the ground-truth
  metres (one number per line). The golden replay test only reads this
  directory and skips itself with a printed reason while it is empty.

Capture procedure (plan Task 11 step 3): record a course on the phone, pull
the activity DB (`adb exec-out run-as dev.toufik.track_scribe cat
databases/track_scribe.sqlite | base64`), export the track as GPX, measure the
course from OpenStreetMap routing, and write both files above. Until that
happens, `test/evidence/golden_replay_test.dart` prints its reason and passes
zero tests — it never fakes a verdict.
