# Fidelity baseline — 2026-10-09

The precondition for any sentence about track fidelity: a table of
`scenario | engine distance | truth | error %`. Nothing in this file may
claim a field distance it did not measure.

## Harness calibration (synthetic — never cited as device evidence)

Fixture: `test/evidence/fixtures/synthetic/walk-1km.gpx` — 716 points at
1 Hz, 1.4 m/s, ±10 m random-walk noise (fixed seed 42, per-step jitter/40
clamped at ±10 m; ruling R92). Generated by
`dart run tool/replay.dart --gen`; ground truth exact by construction.

| scenario | engine distance | truth | error % |
|---|---|---|---|
| walk-1km.gpx replayed as walk | 1000.5 | 1000.0 | 0.05 |
| walk-1km.gpx replayed as run | 1000.5 | 1000.0 | 0.05 |

Both rows replay the same 1.4 m/s fixture, so they are identical: 1.4 m/s is
under both sports' speed caps, so no fix is gate-rejected differently. The run
row is a harness sanity check, not a claim about running.

Synthetic injection suite (`test/evidence/synthetic_injection_test.dart`,
3 tests): 1000 m walk ±10 m noise < 1 % error · 25 m teleportation adds no
distance (ر4) · 10 min standing = 0 m and full elapsed (ر6). All pass.

**Conclusion the table supports (and only this):** the replay harness and
the engine's rules are calibrated — a synthetic 1 km at ±10 m noise lands
0.05 % off. It says nothing about device GPS accuracy.
